# dsh-open-viewed-image

让 DeepSeek Harness（DSH）在助手看图时，自动把那张图打开在**右侧边栏**。

助手每次用 `read_image` 成功读取一张图片，右侧边栏就展开显示它；下一张图会替换上一张，侧栏始终只留最新的一张。

## 效果

- **自动**：不需要点任何东西，读图即显示。
- **替换而非堆叠**：同一会话里新图换掉旧图，不会攒出一排标签页。
- **跟随当前会话**：只在你正在看的会话里生效，后台会话读图不会抢走侧栏。
- **复用 DSH 原生预览**：图片默认适应栏宽、可拖动平移、可缩放。你已安装的其他图片预览增强插件会一并作用在这里。

## 安装

在 DSH 的 **设置 → 插件 → 添加插件** 中填入包名：

```
@imaegoo/dsh-open-viewed-image
```

或从源码目录安装：把仓库克隆下来，用 **添加插件** 选择该目录。

安装后无需任何配置，也没有需要开关的设置项。下一次助手读图时右栏会自己出现。

## 触发条件

只有同时满足以下条件才会打开：

1. 工具是 `read_image`；
2. 调用**成功**（读取失败不打开任何东西）；
3. 路径带图片扩展名：`.png` `.jpg` `.jpeg` `.gif` `.webp` `.bmp` `.ico` `.svg`；
4. 这个会话正显示在屏幕上。

## 已知限制

- **只认扩展名。** `read_image` 也支持无扩展名路径（按文件签名识别格式），这类调用不会被自动打开 —— 用文本查看器打开二进制文件没有意义。
- **需要右侧栏。** 右栏的文件预览由 DSH 自带包提供；组合里没有它时插件保持不活动，不会报错，但也不会打开图片。
- **不做读取授权。** 能否读到文件仍由会话自身的文件访问规则决定，插件只是把已经成功读到的那条路径交给侧栏。
- **只跟踪当前会话。** 这是有意设计，避免后台会话突然打断你的视线。代价是同时看多个会话时，只有当前那个会自动打开。

## 实现说明

插件的 Host 半部分是空的（不注册工具、提示词或会话事件，对模型完全不可见）。逻辑全在浏览器侧：

- 订阅当前会话的事件流，把 `tool/call` 与 `tool/result` 按 `callId` 配对；
- 只对**实时追加**的事件作出反应，因此打开一个已有历史的会话不会把过去读过的图一股脑打开；
- 用 `ctx.sidebarRight.openResource()` 打开 `dsh-resource://file/session/<id>/<path>` 地址，新图带 `replaceTab` 替换上一张。

## 开发

```
client.js           浏览器侧（全部逻辑）
index.js            Host 侧（空实现）
cordis.patch.yml    bundle 条目
locale/{en,zh}.json 插件列表里的标题与描述
docs/DETAIL.md      插件详情页
test/plugin.test.cjs 逻辑测试
```

`test/plugin.test.cjs` 是纯 Node 的逻辑测试，不需要浏览器，覆盖成功/失败打开、非图片过滤、替换、历史不回放、切换会话等边界：

```
npm test
```
