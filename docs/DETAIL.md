# 查看图片时自动打开侧栏

助手用 `read_image` 看图时，这个插件会自动把那张图片在右侧边栏打开。它不改变模型看到的内容，也不改变工具返回的结果，只是把「正在看的那张图」放到你眼前的侧栏里。

## 行为

- **触发**：一次 `read_image` 调用**成功**后打开对应文件。读取失败（文件不存在、不是受支持的图片格式等）不打开任何东西。
- **替换**：同一会话里新打开的图片会替换掉上一张，侧栏始终只显示最新的一张，不会越堆越多标签页。
- **时机**：跟随你当前正在看的会话。切到别的会话就不再跟随原先那个会话的新图片。
- **范围**：只跟踪当前在屏幕上的会话，读图发生在后台会话时不会打断你的视线。

## 使用

安装后无需配置，也没有需要打开或关闭的设置项。下一次助手读图时，右侧边栏会自己展开并显示那张图片。

侧栏用的是 DSH 自带的文件预览：图片默认适应栏宽，支持拖动平移，以及在栏内缩放。所以之前已经安装的图片预览增强类插件，会一并作用在这里打开的图上。

## 已知限制

- **只认扩展名**：插件按 `.png`、`.jpg`、`.jpeg`、`.gif`、`.webp`、`.bmp`、`.ico`、`.svg` 判断哪些读取值得打开。`read_image` 本身支持无扩展名路径（按文件签名识别格式），这些调用不会被自动打开。
- **需要右侧栏**：右栏的文件预览由 DSH 自带包提供。组合里没有它时，插件不会报错，但也打不开图片。
- **不做读取授权**：能否读到文件仍由会话自身的文件访问决定，插件只是把已经成功读到的那条路径交给侧栏。
- **只跟踪当前会话**：这是有意为之，用来避免后台会话突然抢走侧栏。代价是同时看多个会话时，只有当前那一个会自动打开。
